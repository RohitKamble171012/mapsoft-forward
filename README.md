# Mapsoft Redesign

Create a **premium, highly animated, modern SaaS/IT technology company landing page** for **Mapsoft Technologies LLP**, redesigning their existing website into a completely new visual experience.

REFERENCE WEBSITE:
https://maptechsoft.com/home

IMPORTANT:
Use the existing website as the **content source**. Preserve and reuse the company's real information, services, products, statistics, portfolio categories, team information, technologies, FAQs, contact information, and business messaging. Do NOT invent fake company information.

This is currently a **DEMO/REDESIGN CONCEPT**, so build a polished **single-page landing page only**. Do not build all inner pages yet.

==================================================
CORE DESIGN DIRECTION
=====================

The website must feel like a **high-end modern technology/software company**, not a traditional corporate template.

Visual inspiration:

* Premium SaaS websites
* Modern enterprise software companies
* Awwwards-level web design
* Framer-style smooth interactions
* Linear / Vercel / Stripe level visual cleanliness
* Modern enterprise technology branding

The design should communicate:
**Trust + Technology + Innovation + Enterprise + Premium Quality**

BACKGROUND:

* Predominantly WHITE
* Very clean and spacious
* Use subtle off-white sections (#F8FAFC / #F9FAFB) where needed
* Avoid excessive gradients
* Avoid dark website design
* Avoid visual clutter

PRIMARY COLOR:
Use **deep electric blue** as the main brand accent.
Suggested primary: #2563EB
Supporting colors:

* #0F172A for text
* #64748B for secondary text
* #E2E8F0 for borders
* White for backgrounds

The blue should be used strategically for:

* CTA buttons
* highlights
* icons
* interactive states
* small gradients/glows
* important numbers
* section accents

Do NOT make the entire website blue.

==================================================
ANIMATION IS CRITICAL
=====================

This must be a **FULLY ANIMATED WEBSITE**.

Do NOT create a static website with a few hover effects.

Use sophisticated, smooth animations throughout the entire page.

Use:

* Framer Motion
* scroll-triggered animations
* staggered entrance animations
* smooth fade + slide animations
* scale animations
* parallax effects
* animated counters
* hover transformations
* magnetic-style CTA hover effects
* card hover elevation
* image reveal animations
* text reveal animations
* animated gradients
* subtle floating elements
* smooth section transitions
* viewport-based animations
* horizontal scrolling/marquee elements
* animated progress indicators
* micro-interactions

Animations must feel:
**smooth, premium, intentional and expensive**

Avoid:

* cheesy animations
* excessive bouncing
* spinning everything
* slow animations
* distracting effects
* animations that hurt readability

Use animation durations around 0.4–0.8 seconds for most interactions.
