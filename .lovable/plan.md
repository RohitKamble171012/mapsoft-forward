# Plan: Second Mapsoft demo in a new project (keeping this one live)

## Goal
Create a second, independent demo of the Mapsoft Technologies landing page in a
brand-new Lovable project, while leaving THIS project's preview and published
link live and unchanged.

## Why a new project
- Each Lovable project has its own preview + published URLs. Editing this project
  would update the same preview in place (overwriting the demo you like).
- A new project gives the second demo its own live links, completely decoupled
  from this one.

## Steps

### 1. Lock in the current demo (this project) — do not edit further
- Stop making changes here so the preview stays exactly as you want it.
- Recommended: publish this project now to get a permanent public URL that is
  frozen to this design. (Frontend publish requires clicking **Update** in the
  publish dialog.)

### 2. Create the new project (you do this in Lovable)
- From the Lovable dashboard, start a **New project** / new chat.
- This opens an independent agent session for the second demo with its own
  preview and published links. This project is not affected.

### 3. Carry over authenticity (handled in the new chat)
- Reuse the real content + your Mapsoft logo from maptechsoft.com.
- Re-acquire the same site imagery (team photos, client logos, portfolio shots,
  tech icons) directly from the reference site so the new demo stays authentic.
- Same real facts: 39+ clients, 48+ projects, 24/7 support, 39+ workers; India
  (Nagpur) + USA office details; 17 services across 6 practices; ERP / CRM /
  Accolent ERP products.

### 4. Choose the new demo's direction (decide at start of the new chat)
One of:
- **Different visual concept** — same brand/content but a fresh look (e.g. dark
  premium, editorial, bento-grid, or a different accent palette) so the two
  demos feel distinct.
- **Evolution** — keep this design language and refine specific sections.

## What I'll do right after approval
- Give you a ready-to-paste starter prompt + design brief (content, real stats,
  office details, section list, asset sources, and the chosen direction) so the
  new project chat can build the second demo quickly without re-explaining.

## Note
Creating the new project itself is a dashboard action on your side; I cannot
spawn a separate project from inside this session. The build happens in the new
project's chat using the brief above.
